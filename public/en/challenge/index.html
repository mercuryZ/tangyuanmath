The Multiplication Challenge

Ten levels, ten questions each, every answer correct to advance — the Challenge is where fluent multipliers find out how fluent they really are. Each level gets a 120-second clock, but the rule that matters is accuracy: one miss and the level comes back. Speed is the seasoning here, not the meal.

Start the Challenge Prefer untimed? Practice instead

Your level is saved in the game — leave anytime and the next visit starts from where you stopped, with a level-0 warm-up available whenever you want to start calm.

How the levels work

  • Level 0 — the warm-up. Gentle small-number questions to settle in; a safe place to start for first-timers and a good re-entry after a break.
  • Levels 1–10 — the climb. Numbers grow level by level, from small tables up to two-digit × two-digit. Ten questions per level, all correct to pass.
  • 120 seconds per level. Enough time to think, not enough to dawdle — most children finish well inside it once the facts are solid. Optional speed goals appear for confident learners.
  • Misses still learn. Challenge mistakes land in the same mistake book as practice misses, and the hint system explains them after the round.

A mid-level question

Before you climb

The Challenge assumes the times tables are already comfortable — if a round of untimed times-tables practice still feels slow, that's the better place to be today, and the 2-digit × 2-digit mode is where the top levels' material gets learned calmly. The ladder, in order: tables → practice modes → this climb.
