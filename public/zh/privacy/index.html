汤圆数学是什么

汤圆数学是一款免费、友好的网页游戏，帮助学习者练习乘法（最高到两位数 × 两位数），提供不限时练习、10 关挑战和错题重练，支持中文和英文。本政策说明本应用收集哪些数据以及如何使用。

本应用发布在 https://tangyuanmath.com。我们是下文所述账号数据的控制者，可通过 hi@tangyuanmath.com 联系我们。本政策适用于本网站、游戏本体以及可选的家长账号。

一句话版本

游戏无需账号即可完整使用：大多数人完全在浏览器里玩，练习数据不会离开自己的设备。家长可以自愿创建账号（邮箱 + 密码，或使用 Google 登录），以便在多台设备间同步孩子的学习数据。我们没有广告、没有统计追踪、没有任何第三方脚本，也从不售卖个人数据。

我们收集什么

1. 以访客身份游玩（无账号）

所有数据只保存在你浏览器的本地存储中，绝不会发送到我们的服务器。游戏会保存：

  • tm_records — 最近的练习记录（最新 100 组、最长一年）
  • tm_wrongbook — 做错的题目，用于错题重练
  • tm_settings — 你的偏好设置（语言、动画等）
  • tm_lang、tm_challenge_level — 语言选择和挑战关卡进度

2. 家长账号（邮箱 + 密码）

如果你创建账号，我们的服务器会保存：

  • 你的邮箱地址（用于登录、以及发送验证/重置密码邮件）
  • 一份哈希后的密码（我们从不保存明文密码）
  • 你的语言和时区偏好
  • 账号创建时间
  • 如你添加：孩子档案（昵称和所选头像）；如你开启同步，还有孩子的练习记录和错题本

3. 家长账号（使用 Google 登录）

当你选择使用 Google 登录时，我们只申请最小范围的 openid 和 email 权限。我们的服务器只会收到：

  • 你的邮箱地址（已由 Google 验证属于你）
  • 一个Google 账号标识——仅够下次认出你

我们不申请任何其他资料（不申请姓名、头像、通讯录或日历）。上文所述的、可选的孩子档案和同步的学习数据同样可能存入你的账号。

我们如何使用这些数据

  • 提供游戏——记住进度、偏好和错题重练
  • 登录——认出你，并在你的多台设备间同步学习数据
  • 发送账号邮件——仅限邮箱验证和密码重置
  • 提供支持——回复你发来的问题

我们不做的事

  • 没有广告，也没有任何广告或追踪脚本
  • 不做访客统计分析，也不做用户画像
  • 不出售、不出租个人数据给任何人
  • 不使用第三方字体或外嵌内容——页面只加载本站文件
  • 不生成任何 AI 图像。汤圆数学是一款数学练习游戏。Google 登录仅用于身份验证，我们不会用 Google API 数据（或任何数据）来生成、创建、训练或传播 AI 生成图像——包括非自愿亲密图像（NCII）或任何其他合成媒体。

Google 数据如何使用

Google 数据（你的邮箱地址和 Google 账号标识）仅用于登录、以及将你的账号与孩子同步的学习数据关联。不用于任何其他目的，也不会与其他任何 Google 数据合并或透露给第三方。授权在 Google 自己的网站上完成（我们的页面不嵌入任何 Google 脚本或按钮）。你可以随时在 Google 账号权限管理中查看或撤销我们的权限。Google 如何处理你的数据见 Google 隐私政策。我们对从 Google API 收到的数据的使用遵循 Google API 服务用户数据政策，包括其限制使用要求。

数据共享

我们不会向任何第三方共享、出售或出租个人数据。你的数据只保存在我们自己的服务器上。Google 仅在登录时充当身份提供方。

数据存储在哪里

账号数据存放在我们应用服务器所挂载的持久磁盘上的 SQLite 数据库中，服务器由 Render（Render Services, Inc.，美国）托管。我们不使用任何独立的统计、广告或客户管理服务商。由于服务器位于美国，你提供的数据可能会被传输到美国并在那里处理；创建账号即表示你同意该传输。你的浏览器与服务器之间的所有流量都使用 HTTPS 加密。

你的选择与权利

  • 不注册也能玩。游戏以访客身份即可完整使用；该模式下不会有任何数据到达我们的服务器。
  • 访问与导出。在家长中心可以下载 JSON 导出文件，包含你的账号、孩子档案、练习记录和错题本。
  • 更正。你可以随时在家长中心修改语言和时区。
  • 删除。在家长中心删除账号会永久移除你的邮箱、Google 关联、孩子档案和全部同步的学习数据，且不可恢复。
  • 反对或提问。请发邮件至 hi@tangyuanmath.com，我们会回复。

如果你位于欧洲经济区、英国或瑞士，你还有权向当地数据保护机构投诉。我们处理账号数据的法律依据是履行与你之间的约定（提供同步功能）以及你的同意；你可以随时通过删除账号撤回该同意。

数据保留与删除

  • 访客数据只存在你的浏览器里，清除浏览器数据即可删除；也可随时在游戏内通过「设置 → 清除我的全部数据」删除。
  • 账号数据会一直保留到你自己删除为止。你可以在家长中心导出数据（JSON）并删除账号；删除账号会从服务器移除你的邮箱、Google 关联、孩子档案和同步数据。
  • 登录会话会在 7 天后自动过期。

安全

所有流量都使用 HTTPS。密码只以哈希（bcrypt）形式存储。我们只申请登录所需的最小 Google 权限范围，也不会超过上述期限保存数据。

关于儿童

汤圆数学为低龄学习者做了安全设计：不要求儿童提供任何个人信息，孩子在游戏中做的任何事都不会被传送到任何地方——除非家长选择创建账号并同步数据。账号面向家长或监护人。如果你认为有儿童自行创建了账号，请联系我们，我们会予以删除。我们按适用的儿童隐私规则（如 COPPA、GDPR）设计。

本政策的更新

如果我们的做法发生变化，会先更新本页再实际生效。
